# Hugging Face 中文汉化

一个用于汉化 Hugging Face 网页界面菜单和常用内容的用户脚本。

## 安装

先安装 Tampermonkey、Violentmonkey 等用户脚本管理器，再打开下面的链接安装：

- [安装最新版脚本](https://raw.githubusercontent.com/yamazakitouma/huggingface-chinese/main/huggingface-chinese.user.js)
- [查看源代码](https://github.com/yamazakitouma/huggingface-chinese/blob/main/huggingface-chinese.user.js)

脚本匹配以下站点：

- `https://huggingface.co/*`
- `https://*.huggingface.co/*`
- `https://hf-mirror.com/*`

## 功能

- 汉化导航栏、筛选器、按钮、模型、数据集、Space、文档等常用文本
- 支持 Hugging Face 的动态 DOM 和单页应用页面跳转
- 可通过脚本菜单开启或关闭正则翻译

## 初始来源

本仓库初始版本基于用户提供的 Hugging Face 中文化用户脚本 v1.2.0，原脚本元数据作者为“蛋定的文弱书生”。后续修改、维护和发布均在本仓库进行。
